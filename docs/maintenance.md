# 公开维护与热门工具更新

本合集公开收录产品经理工作流相关的热门与有价值项目。Star、近期维护、任务相关性一起参考；累计 Star 不当作最近一周涨幅或实际使用人数。

自动更新通过 GitHub Actions 完成：每周一北京时间 09:00（UTC 01:00）刷新已收录项目的 Star、推送时间、归档状态和 GitHub 许可识别，再生成分类目录并校验。也可在 Actions 页手动运行。定时任务的实际执行时间受 GitHub 排队影响。

新增项目、工作流归类、迁移判断、README 许可说明由维护者人工筛选；自动化不会把所有高 Star 仓库自动收进来。欢迎通过 Issue 或 PR 提交候选与修正。

若上游 API 请求失败，脚本保留旧值及旧核验日期，工作流失败且不提交半更新目录。维护者可在 Actions 日志查看失败项目并重试。
